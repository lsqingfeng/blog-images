# Avatar frame sources

- `flag-glow.png`, `silk-frame.png`, `golden-years.png`: generated with OpenAI image generation for this project.
- `cloud-ring.png`: adapted with OpenAI image generation from the Pixabay asset “Chinese Spring Festival Cloud Frame” by franklynzhao: https://pixabay.com/illustrations/chinese-spring-festival-cloud-frame-7697452/
- `heritage-border.png`: adapted with OpenAI image generation from the Pixabay asset “Chinese Style, Frame, Red” by we-o_rd35r315v5crgxvps: https://pixabay.com/illustrations/chinese-style-frame-red-border-8580622/
- `glory-china.png`, `tiananmen-beijing.png`, `huabiao-ribbon.png`, `shanhe-ruhua.png`, `ribbon-circle.png`, `guochao-peony.png`: adapted from open-source celebratory assets (kangleyunju/guoqing).
- `flag-badge.png`: adapted from open-source celebratory avatar assets (szisa/avatar_maker).
- `shouchi-hongqi.png`, `guoqing-kuaile.png`: adapted from open-source celebratory avatar assets (generate-avatar / avatar-maker).
- `woai-zuguo.png`, `shengshi-huabiao.png`, `maihui-hongqi.png`: adapted from open-source celebratory assets (kangleyunju/guoqing).

All assets have been resized to 800x800 and heavily optimized using 256-color palette quantization to ensure lightweight Mini Program bundle size (<100KB per image).
